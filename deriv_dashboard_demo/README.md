# Deriv-style Dashboard Demo

An independent, front-end-only dashboard practice project inspired by the layout references supplied for a web-development challenge.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Use the left navigation to switch between Home, CFDs, Exchange, Options, Portfolio and Profile.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `app.js` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Included
- Responsive desktop and mobile layout
- Dashboard navigation
- Home, CFDs, Exchange, Options, Portfolio and Profile pages
- Demo-only modal interactions, search, filters and amount controls
- Fictional balances and sample market rows

## Important
This is an independent educational UI demo, not an official Deriv website and not affiliated with Deriv. It does not connect to Deriv, authenticate users, fetch live prices, create accounts, accept deposits, transfer funds, or execute trades. All balances and market data are fictional. Do not enter real passwords, payment details or personal information.
